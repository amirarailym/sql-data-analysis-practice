# SQL Data Analysis Practice

This repository documents my SQL practice while completing the
"SQL for Data Analysis: Beginner MySQL Business Intelligence" course on Udemy.

## Dataset

The exercises use the Maven Movies sample database, which represents
a fictional movie rental business.

## Purpose

I'm using this repository to practice and document SQL concepts including:

- Aggregate functions
- GROUP BY
- JOINs
- CASE statements
- Subqueries and CTEs
- Window functions

The SQL files contain my own practice queries and notes as I work through
the material.
